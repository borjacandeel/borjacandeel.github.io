Proyecto destacado · Radical Records

AutoPrevias

Generador automático de previas musicales para la discográfica Radical Records

Aplicación de escritorio para macOS y Windows que desarrollé íntegramente yo para el sello. Analiza cada tema (BPM, tonalidad y estructura), distingue drops, subidas y descansos, corta sobre el compás exacto y exporta la previa lista para enviar o publicar, con la carátula y los metadatos del sello.

  • Para qué sirve: sacar la previa promocional de cada lanzamiento del catálogo en minutos, sin editar a mano.
  • Previas de 15 s, 30 s, 60 s o 2 min según el destino: redes sociales, radio, sellos y A&R, DJ y club o envío seguro.
  • Vídeos animados «Radical Neón» en 9:16, 1:1 y 16:9 para TikTok, Reels y YouTube, con la carátula y la identidad del sello.
  • Modo promo antifugas: firma de voz repetida y MP3 a 128 kbps con la marca «PROMO — NO DISTRIBUIR».

Versión 6.1.0 · macOS (Apple Silicon) y Windows · Ediciones Basic y Plus con licencia por clave · Instaladores y actualizaciones automatizados con GitHub Actions.

  • Python
  • PySide6 / Qt 6
  • librosa
  • NumPy · SciPy
  • pedalboard
  • FFmpeg
  • GitHub Actions

Sistema de monitorización de infraestructura

Métricas, alertas e informes desatendidos para Proxmox

Herramienta propia de monitorización para nodos Proxmox. Recoge métricas de estado, detecta incidencias y genera informes HTML periódicos que se envían por email de forma desatendida. Diseñada bajo dos principios: autocontenida (sin dependencias externas) e idempotente (reejecutable sin efectos secundarios). Desarrollada de forma iterativa hasta la versión 4.x, con corrección de condiciones de carrera e integración con Monit.
